## Process Flow

### UPSTREAM — Executive (Maintenance Performance)

- Perform Asset Register initiated
- Perform Work preparation & engagement with relevant stakeholder
- Perform desktop verification
- Determine if Site verification required

### Manager (Maintenance Support)

- Acknowledge site verification plan
- Initiate Asset Site verification with Operation Personnel
- Review Asset Register

### Supervisor or Appointed Focal

- Complete Site verification
- Provide data for Asset Master completion

### Engineer (Process Safety Management)

- Setup Functional Location & Equipment Data

### Reliability Engineer

- Provide input on SCE identification
- Identify ECA & SCE
- Conduct Equipment Criticality Assessment (ECA) for PMMS initiated
- Conduct Equipment Criticality Assessment (ECA) for PMMS completed
- Finalize Asset Register (Syndicate with Manager (Maintenance Support))
- Develop BOM
  - 3 years
  - BOM development continued while other process ongoing

### Field Manager

- Complete Asset Register in system
- Asset Register approved
- Receive acknowledge
- Perform Asset Register completed, Perform Planning Data Setup initiated

---

**Conditions/Gates:**

- Site verification required
- Site verification not required
- Data input for Asset Master not completed
- Data input for Asset Master completed
- Asset Register rejected
